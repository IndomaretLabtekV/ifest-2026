# Analysis scripts

Run in order with `python <script>`. Data is read from `final/data/`, figures go to `final/outputs/figs/`, caches to `final/work/`.

| Script | Question it answers | Key finding |
|---|---|---|
| `01_data_quality.py` | How dirty are the raw strings? | Decimal comma vs thousands sep (resolved by lag continuity), text months, `-9999` sentinels, sign flips, aux traps (`aux_constant` 0 in train / -1,999 in test; `aux_twin` mapping swaps between splits) |
| `02_panel_structure.py` | Duplicates, overlap, time order | 9,728 duplicated (id, origin) pairs; shuffled `origin_id` recovered into one 168-month chain; test origins are >=12 months from train and from each other |
| `03_target_definition.py` | What is the label? | `label = 1 <=> ws_cum(t+1) <= 0.6 * clim_next` (99.99% once clim scale is fixed) |
| `04_preprocessing.py` | Does each repair step actually restore true values? | Scored against cross-row ground truth; budget identity `ws = bf + qf + inflow` lifts ws recovery 48.5% -> 80.7% |
| `05_eda_target_features.py` | Target behaviour, feature ranking, drift | Persistence alone AP 0.60; adversarial AUC 1.0 is an origin-feature artefact |
| `06_clim_gap.py` | Filling Jun-Sep climatology for test-only HUCs | kNN analog: median log err 0.13 vs 0.27 cyclic |
| `07_cv_ablation.py` | Which data/feature decisions raise AP? | raw 0.633 -> repaired 0.644 -> FE 0.694 -> minus origin feats 0.701 |
| `08_enhance.py` | Continuous-target regression, HUC target encoding | Both hurt (0.617, 0.588) |
| `09_models.py` | LGB vs XGB vs CatBoost vs blend | Rank blend 0.7033 best |
| `10_probes.py` | Where does the model fail on the leaderboard? | Writes subset-swap probe submissions |

Shared modules: `common.py` (paths, parsers), `prep.py` (repair), `fe.py` (features). The Kaggle notebook is generated by `notebook/build_final.py`.
